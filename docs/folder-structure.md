# Folder Structure: Sports Club Management System

**Stack:** PostgreSQL · Prisma · Express · React · Node.js
**Language:** JavaScript only (no TypeScript), **ES Modules** everywhere (`"type": "module"`, `import` / `export`)
**Pattern:** modular (feature-based): every feature owns its routes, controller, service and validation in one folder.

---

### 3.1 Inside every server module

```
modules/bookings/
├── booking.routes.js           # URLs + middleware chain
├── booking.controller.js       # reads req, calls service, sends response
├── booking.service.js          # business rules + Prisma queries
├── booking.validation.js       # imports Zod schemas from @club/shared (+ server-only checks)
└── index.js                    # export { default as bookingRoutes } from './booking.routes.js'
```

| File | Responsibility | Must NOT do |
|---|---|---|
| `*.routes.js` | Define endpoints, attach `auth`, `authorize`, `validate` | Contain logic |
| `*.controller.js` | Take validated input, call service, return JSON | Talk to Prisma directly |
| `*.service.js` | Business rules, Prisma queries, transactions | Read `req` / `res` |
| `*.validation.js` | Zod schemas for body, params, query | Query the database |
| `index.js` | Public export of the module | Anything else |

## 5. Naming Conventions

| Item | Convention | Example |
|---|---|---|
| Folders | kebab-case | `shop-orders/`, `social-play/` |
| Server files | `<name>.<layer>.js` | `booking.service.js` |
| React components | PascalCase `.jsx` | `BookingForm.jsx` |
| Hooks | camelCase starting with `use` | `useCreateBooking.js` |
| Zod schemas | camelCase ending in `Schema` | `createBookingSchema` |
| Prisma models | PascalCase singular | `Booking`, `Member` |
| API routes | plural, kebab-case | `/api/shop-orders` |
| Imports | always include `.js` extension (ESM rule) | `import { prisma } from '../../lib/prisma.js'` |

### `server/src/middleware/validate.js`

```js
export const validate = (schemas) => (req, res, next) => {
  for (const key of ['body', 'params', 'query']) {
    if (!schemas[key]) continue;
    const result = schemas[key].safeParse(req[key]);
    if (!result.success) {
      return res.status(400).json({
        message: 'Validation failed',
        errors: result.error.flatten().fieldErrors,
      });
    }
    req[key] = result.data;
  }
  next();
};
```

### `server/src/modules/bookings/booking.service.js`

```js
import { addMinutes, startOfDay, endOfDay } from 'date-fns';
import { prisma } from '../../lib/prisma.js';
import { ApiError } from '../../utils/ApiError.js';
import { calculateCourtPrice } from '../../utils/pricing.js';
import { SESSION_MINUTES, MAX_PER_DAY } from '@club/shared';

export const createBooking = async (data, user) => {
  const [h, m] = data.startTime.split(':').map(Number);
  const startTime = new Date(data.date);
  startTime.setHours(h, m, 0, 0);
  const endTime = addMinutes(startTime, SESSION_MINUTES);

  return prisma.$transaction(async (tx) => {
    if (data.memberId) {
      const count = await tx.booking.count({
        where: {
          memberId: data.memberId,
          status: { not: 'CANCELLED' },
          startTime: { gte: startOfDay(startTime), lte: endOfDay(startTime) },
        },
      });
      if (count >= MAX_PER_DAY) {
        throw new ApiError(422, 'Member already has 2 bookings today');
      }
    }

    const price = await calculateCourtPrice(tx, data.courtId, data.memberId);

    try {
      return await tx.booking.create({
        data: {
          courtId: data.courtId,
          memberId: data.memberId ?? null,
          walkInName: data.walkIn?.name ?? null,
          walkInPhone: data.walkIn?.phone ?? null,
          startTime,
          endTime,
          price,
          createdById: user.id,
        },
      });
    } catch (err) {
      // raised by the PostgreSQL exclusion constraint "no_overlap"
      if (err.message?.includes('no_overlap')) {
        throw new ApiError(409, 'This court is already booked for that time');
      }
      throw err;
    }
  });
};
```

```prisma
}
```

**No-double-booking constraint** (create an empty migration with `npx prisma migrate dev --create-only`, then add):

```sql
CREATE EXTENSION IF NOT EXISTS btree_gist;

ALTER TABLE "Booking"
  ADD CONSTRAINT no_overlap
  EXCLUDE USING gist (
    "courtId" WITH =,
    tstzrange("startTime", "endTime") WITH &&
  )
  WHERE (status <> 'CANCELLED' AND type = 'NORMAL');
```
