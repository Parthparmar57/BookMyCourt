# BookMyCourt Owner OS: Admin Features by Section

**Role:** Owner / Admin
**Club:** The Champions Club

## Legend

| Symbol | Meaning |
|---|---|
| **Full** | View, create, edit, delete |
| **View** | Read only |
| **Approve** | Approve or reject |
| **Export** | Download / share |
| ✅ | From the requirements document |
| ➕ | Sensible addition (not in the document) |

## 1. Executive Dashboard

**Purpose:** a one-screen view of how the club is doing.

| Feature | What to show | Access | Doc |
|---|---|---|---|
| Period filter | Today / This Week / This Month toggle that applies to the whole dashboard | View | ✅ |
| Total revenue card | Total earnings for the selected period | View | ✅ |
| Revenue by source | Split between Courts, Shop and Bar (chart + numbers) | View | ✅ |
| Revenue by payment mode | Split between Cash, Card, UPI/Online | View | ✅ |
| Amount owed | Total unpaid expenses, salaries due and unpaid invoices | View | ✅ |
| Today's bar earnings | What the bar earned today | View | ✅ |
| Membership alerts | Count of memberships expiring soon | View | ✅ |
| Low-stock alerts | Shop items below minimum stock | View | ✅ |
| New enquiries | Count of new leads not yet followed up | View | ✅ |
| Pending leave requests | Count waiting for approval, with a link to HR | View | ✅ |
| Court occupancy today | How many slots are booked vs free | View | ➕ |
| Share / export dashboard | Download or share the numbers | Export | ✅ |

## 9. Settings (Recommended Addition to Sidebar)

The document says "Plans change" and that each plan defines "court rates to discounts at the shop and the bar". The owner needs a place to manage these.

| Feature | What to show | Access | Doc |
|---|---|---|---|
| Plan management | Edit Gold/Silver/Junior prices, court rates, shop discount and bar discount | Full | ✅ |
| Court management | Add or edit courts and walk-in rates | Full | ➕ |
| Booking rules | Session length (1 hr), slot interval (30 min), daily limit (2) | Full | ➕ |
| Staff user accounts | Create logins for staff and assign roles | Full | ➕ |
